The site got a rebuild. New look, corrected setup steps, and this news section.

From here on I will post here when a release lands or when something changes that is worth knowing about. Each post is a plain Markdown file in the site repo, so writing one is quick.

## How posts work

Every article lives in `src/content/news/` as a `.md` file. The header image goes in `public/news/` and the post points at it. Set a title, a date, and an author in the frontmatter and it shows up here automatically. The newest post is the one featured on the home page.

If you run a server on Stratum and hit something odd, the Discord is the fastest way to reach me.
